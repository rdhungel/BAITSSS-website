Known Issues

Document limitations and unresolved defects openly.

Formal BAITSSS Desktop releases will list verified known issues here so users can distinguish a documented limitation from an unexpected software problem.

Current status

BAITSSS Desktop has not yet reached its first formal public release. Development defects are still being resolved during release preparation, so this page does not present the internal development ledger as if it were a released-product known-issues list.

Pre-release

No formal public known-issues list has been issued yet.

The first release-specific list will be published after the release candidate is frozen and verified.

How issues will be reported

  • Affected version
  • Area of the software such as project setup, data import, execution, Results, export, or installer
  • Observed behavior
  • Workaround, when one is verified
  • Status such as open, fixed for next release, or resolved
  • Scientific impact when an issue can affect model inputs, calculations, or outputs

Report a problem

When reporting an issue, include the BAITSSS version or build, the project step where the problem occurred, what you expected, what occurred, and enough information to reproduce the behavior when possible.
