Evidence

What does the evidence show?

BAITSSS separates peer-reviewed studies, software testing, and current scientific work. Results from one study are kept within the conditions tested in that study.

Interpretation

Keep results within the conditions tested

A result from one crop, site, climate, period, or comparison does not establish performance everywhere. Refer to the publication for the exact result and study conditions.

Software testing

Software testing and scientific validation answer different questions

Execution equivalence

Modernization tests compare new execution methods with the accepted scientific reference under defined numerical criteria.

Checkpoint and restart

Stop, resume, and restart behavior is tested separately from scientific accuracy.

Performance

Runtime tests measure computational performance. Faster computation does not establish scientific accuracy.

Ongoing evaluation

Current scientific questions

Resistance behavior and sensitivity

Resistance connectivity, parameter sensitivity, stability behavior, and transferability continue to be evaluated.

Independent observations and comparisons

Thermal observations, ET products, field measurements, soil-water observations, and irrigation records differ in scale, timing, and uncertainty. Those differences matter when results are compared.

Keep the evidence separate: published studies, software tests, and ongoing experiments provide different information and should not be treated as equivalent.
