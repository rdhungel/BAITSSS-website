Access Principles

BAITSSS software access is controlled by purpose and agreement.

These principles explain the basis on which BAITSSS Desktop, scientific validation, research use, and source-code access are considered.

1. Public review does not require software access

Anyone may review the public BAITSSS website, publications, scientific evidence, demonstrations, screenshots, videos, and other public materials. Personal interest or curiosity does not by itself create a right to receive the desktop software or source code.

2. Desktop software access is institutional or organizational

Use of BAITSSS Desktop is provided through an approved arrangement with the responsible university, agency, company, laboratory, or other organization. Individual researchers, students, faculty members, consultants, or other users operate under that arrangement rather than receiving unrestricted personal access.

3. Evaluation and scientific validation are different

General evaluation is not an unrestricted pathway for obtaining BAITSSS. If the proposed activity involves comparison with field measurements, independent observations, other models, or publication-quality testing, it is treated as a defined scientific validation or research activity and requires an agreed institutional arrangement.

4. Access is specific to the approved purpose

  • Academic research and teaching
  • Scientific validation or collaborative research
  • Government or agency use
  • Commercial or professional use
  • Demonstration or formal review
  • Source-code access, when separately approved

These uses are not automatically interchangeable. Approval for one purpose does not imply approval for another.

5. Software access does not imply source-code access

The packaged BAITSSS Desktop application and BAITSSS source code are separate forms of access. Receiving or using the desktop software does not grant a right to obtain, redistribute, modify, or inspect source code unless that permission is explicitly provided.

6. Research conclusions remain scientific conclusions

BAITSSS access is not conditioned on producing favorable results. However, research or validation use must be conducted under the agreed purpose, software version, data, methods, and reporting conditions so that findings can be interpreted correctly and traced to the actual system that was evaluated.

7. Specific agreements control

This page states BAITSSS access principles; it is not itself a software license or research contract. Any approved use is governed by the specific written agreement applicable to that institution, organization, project, or collaboration.

Requests should identify the responsible institution or organization, project lead, intended use, and proposed scientific or professional purpose.
