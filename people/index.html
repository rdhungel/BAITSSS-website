Current development team
BAITSSS Development Team
Desktop software development, scientific continuity, verification, documentation, and release preparation
The current team is responsible for maintaining the supported BAITSSS Desktop route and coordinating the work needed to keep it scientifically traceable and technically maintainable.

The current effort combines experience in evapotranspiration, irrigation and agricultural water management, remote sensing, soil-water processes, field instrumentation, scientific modeling, and software development.

For BAITSSS Desktop V1, that responsibility includes preserving established model behavior while maintaining the desktop workflow, controlling data and parameter authority, verifying numerical behavior, testing run and recovery paths, packaging the runtime, documenting the system, and preparing the first release version.

Scientific interpretation, evidence, uncertainty, validation principles, and reporting responsibility are maintained as one scientific authority on the Science page rather than repeated here.

02 · Current responsibility

What the current stewardship role covers

01 · PRODUCT

Maintain one supported desktop route

Keep project state, data preparation, execution, recovery, Results, provenance, packaging, and documentation connected within one maintained product.

02 · VERIFICATION

Require evidence for change

Use numerical comparison, restart testing, source controls, runtime contracts, parameter audits, and release checks to distinguish demonstrated behavior from assumption.

03 · CONTINUITY

Protect scientific implementation

Software modernization should not silently redefine equations, parameters, state behavior, or reference outputs. Scientific changes require explicit scientific review.

04 · COMMUNICATION

Keep status and limits visible

Document what the software does, what has been verified, what remains under development, and how research or educational collaboration can proceed.
