02 · Shared responsibility

Responsibilities are agreed together

BAITSSS

Software and scientific status

  • Describe the software and scientific status accurately.
  • Provide the agreed materials and software version information.
  • Identify known assumptions and limits of use.
Research user / institution

Inputs and interpretation

  • Use appropriate input data and record its source.
  • Interpret modeled outputs for the intended application.
  • Distinguish modeled irrigation from documented applied irrigation.
