What collaboration can provide

A modeling environment around the research question

Researchers do not need to build an entire spatial and hourly modeling system from the beginning for every project. Where the scientific fit is appropriate, BAITSSS can provide the project workflow, input readiness checks, hourly simulation framework, spatial and pixel level Results, run records, and export tools needed for the computational part of the study.

BAITSSS contribution

  • Provide the agreed software version and project workflow.
  • Describe the scientific status, assumptions, and current limitations accurately.
  • Support reproducible project setup, run identity, Results inspection, and agreed scientific outputs.

Research partner contribution

  • Define the scientific question and provide appropriate input or observational data.
  • Document the source, scale, and meaning of independent measurements.
  • Interpret modeled outputs within the intended scientific application.

Prepare your request

Tell us who you are, the scientific or professional purpose, the site or dataset if known, the type of observations available, and how you would like to use or evaluate BAITSSS. Participation depends on scientific fit, development status, and the scope of the proposed work.
