# BAITSSS Website

Public website repository for BAITSSS scientific software.

## Current status

This repository is being prepared for migration of the reviewed BAITSSS public website. The current ChatGPT-hosted draft remains the working visual reference until the migration is completed and reviewed.

## Planned public site sections

- Home
- Science
- Software
- Evidence
- Research & Education
- Access & Participation
- Development Status
- Origins & Publications
- Contact

## Repository boundaries

- Public website source and approved public assets only.
- Approved public technical documents may be included.
- Internal scientific, commercialization, governance, validation, and development records are not stored here unless separately approved for public release.
- The BAITSSS desktop scientific source code is not part of this repository.
- Domain deployment and public release remain separate from source migration and review.

## Migration status

The initial repository has been created. Website source migration will proceed on a separate migration branch before any public deployment change.
