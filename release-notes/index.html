Release Notes

Track changes by software release.

Each formal BAITSSS Desktop release will be documented here with version identity, release date, major changes, scientific or workflow changes, fixes, compatibility information, and links to known issues.

Current status

BAITSSS Desktop is still in active development and release packaging. A formal public release number and release date have not yet been assigned.

Development build

Pre-release

The current desktop workflow is being finalized through clean-machine testing, installer packaging, broader verification, and release preparation.

  • Formal public version number: pending release verification
  • Release date: pending
  • Final installer package: in progress
  • Release-specific compatibility notes: pending final verification

What each release note will contain

  • Version and release date
  • What changed in the desktop workflow, execution, data handling, Results, or packaging
  • Scientific-impact statement when a change affects model equations, assumptions, parameters, inputs, or outputs
  • Fixes and corrections included in that release
  • Compatibility and migration notes for projects or data when relevant
  • Known issues that remain open at release time
  • Verification status for installer, clean-machine, workflow, and scientific checks
