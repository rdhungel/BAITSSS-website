Development Status

BAITSSS Desktop is under active development.

The scientific model, desktop product, validation program, documentation, and public-access pathway are progressing in parallel. They are related, but they are not treated as the same milestone.

Current working system

From project setup through results

Project and data

Structured desktop workflow

Project setup, area of interest, data readiness, and prepared inputs are integrated into the desktop workflow.

Execution and results

Run and resume workflow

Simulation execution, progress, stopping and resuming, and results review are active parts of the working desktop system.

Quality and documentation

Evidence-first development

Software verification, scientific validation, provenance, and documentation are maintained as distinct evidence tracks.

Active testing

Work still being tested before general release

Runtime robustness

Execution lifecycle, restart behavior, failure visibility, and long-run stability continue to be tested.

Scientific evaluation

Study-specific comparisons, sensitivity analyses, and independent scientific questions continue separately from interface completion.

Release preparation

Installer behavior, documentation, access conditions, and public materials are being prepared before a general release decision.

Release boundary

A working desktop system is not the same as a public release.

Final release readiness requires the software, documentation, access pathway, scientific stewardship materials, and appropriate validation evidence to be considered together. A website, demonstration, pilot build, or completed interface does not by itself mean BAITSSS Desktop has entered general distribution.

Current public position: BAITSSS Desktop remains under active development. Access and participation are handled through the pathways described on this site rather than through a general software download.
