Development Status

BAITSSS Desktop is under active development.

The scientific model, desktop product, validation program, documentation, and public-access pathway are progressing in parallel but are not treated as the same milestone.

Current working system

Project and data

Structured desktop workflow

Project setup, AOI, data readiness, and prepared inputs are integrated into the desktop workflow.

Execution and results

Run and resume workflow

Simulation execution, progress, stopping/resuming, and results review are active areas of the working desktop system.

Quality and documentation

Evidence-first development

Software verification, scientific validation, provenance, and documentation are maintained as distinct evidence tracks.

Active testing

Runtime robustness

Execution lifecycle, restart behavior, failure visibility, and long-run stability continue to be tested.

Scientific evaluation

Study-specific comparisons and sensitivity questions continue independently of interface completion.

Release preparation

Installer, documentation, access conditions, and public materials are being prepared before a general release decision.

Planned

Final release readiness will require the software, documentation, access pathway, scientific stewardship materials, and appropriate validation evidence to be reviewed together. A polished website or demonstration does not by itself mean the software is generally released.
