Development Status

BAITSSS Desktop is under active development.

The model, desktop software, validation, documentation, and access are developing together, but each has its own testing and completion requirements.

Current working system

From project setup through results

Project and data

Desktop workflow

Project setup, area of interest, data readiness, and prepared inputs are integrated into the desktop application.

Execution and results

Run and resume

Simulation execution, progress, stopping, resuming, and Results review are working parts of the desktop application.

Testing and documentation

Separate checks

Software testing, scientific validation, input and version records, and documentation are maintained separately.

Active testing

Work still being tested before general release

Runtime reliability

Run lifecycle, restart behavior, failure reporting, and long-run stability continue to be tested.

Scientific evaluation

Study comparisons, sensitivity analyses, and independent scientific evaluation continue separately from interface work.

Release preparation

Installer behavior, documentation, access conditions, and public materials are being completed before general release.

Release status

A working desktop application is not yet a public release.

Before general release, the software, documentation, access process, scientific-use guidance, and validation need to be reviewed together. A website, demonstration, pilot build, or completed interface does not mean the software is ready for general distribution.

Current status: BAITSSS Desktop remains under active development. Access is handled through the options described on this site rather than through a general software download.
