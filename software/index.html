Desktop software

From scientific model to operational software.

BAITSSS Desktop is being developed as a Windows scientific application that organizes project setup, data readiness, execution, results review, and traceable outputs around the underlying model.

Five-stage workflow

01

Project

Define the project and simulation context.

02

AOI

Establish the analysis area.

03

Data

Review required inputs and readiness.

04

Run

Configure and execute the simulation.

05

Results

Inspect modeled outputs and provenance.

Execution architecture

Prepared inputs

Project data are validated and organized before execution so the run begins from an explicit readiness state.

Hourly model state

The scientific engine advances the gridded water and energy state through the simulation period while retaining checkpoint and provenance information.

Results and exports

Results are presented through the desktop interface and prepared for scientific review and downstream analysis.

Current status

The desktop product is under active development and validation. Software completion and scientific validation are treated separately: a working interface does not by itself establish scientific performance for every application.
