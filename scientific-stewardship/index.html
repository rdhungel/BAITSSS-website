Scientific Stewardship

Interpret the model by what it does, the evidence behind it, and the assumptions that govern it.

BAITSSS outputs are scientific model results. Responsible use requires attention to input provenance, field context, assumptions, application boundaries, and independent evidence.

Interpretation framework

Keep observations, inputs, modeled states, and interpretation distinct.

Observed

Satellite measurements, weather observations or forcing products, field measurements, and other independent records provide evidence at their own spatial and temporal scales.

Supplied

Project geometry, dates, soil properties, rooting assumptions, management information, and other configured inputs define the modeling context.

Modeled

ET components, water-balance states, modeled irrigation, resistance behavior, and other simulated quantities are outputs of the model under those inputs and assumptions.

Responsibilities

Scientific use depends on traceable context.

Input and provenance responsibilities

Weather, vegetation, soil hydraulic properties, rooting depth, precipitation, irrigation information, and model configuration can materially influence later modeled states. Project provenance should be preserved when results are interpreted or shared.

Collaborator responsibilities

Users should retain project context, data provenance, software version, model configuration, and the evidence used to interpret results. Independent evaluation should describe both agreement and disagreement.

Irrigation interpretation

Modeled irrigation is not the same as documented farmer-applied irrigation unless independent records establish that correspondence. A modeled event is part of the water-balance experiment.

Model disagreement and diagnostics

Disagreement with an observation can point to forcing, parameter, structural, scale, timing, or measurement questions. It should be investigated rather than hidden or automatically labeled as a software failure.

Application boundaries

Evidence remains tied to the conditions under which it was established.

Performance established for one study, crop, climate, period, or configuration should not be generalized automatically to every application. Scientific claims should remain connected to the supporting study, comparison data, model version, and relevant assumptions.

Stewardship rule: software usability, engineering reliability, and scientific validity are related but distinct. A functioning workflow does not remove the need for appropriate scientific interpretation.
Why continuous modeling matters

Important field processes continue between satellite observations.

Irrigation, rainfall, transpiration, soil evaporation, drainage, and root-zone depletion continue between observation times. BAITSSS is designed to maintain a continuous modeled accounting of those processes while using observations and meteorological forcing to constrain the trajectory.
