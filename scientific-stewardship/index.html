Scientific Stewardship

Interpret the model by what it does, the evidence behind it, and the assumptions that govern it.

BAITSSS outputs are scientific model results. Responsible use requires attention to input provenance, field context, assumptions, application boundaries, and independent evidence.

Interpretation framework

Separate what was observed, what was supplied as input, what was modeled, and what is inferred from the modeled trajectory.

Input & provenance responsibilities

Weather, vegetation, soil hydraulic properties, rooting depth, precipitation, and irrigation information can materially influence later modeled states.

Irrigation interpretation

Modeled irrigation is not the same as documented farmer-applied irrigation unless independent records establish that correspondence.

Model disagreement & diagnostics

Disagreement with an observation can identify forcing, parameter, structural, scale, or measurement questions and should be investigated rather than hidden.

Known application boundaries

Performance established for one study, crop, climate, or configuration should not be generalized automatically to every application.

Collaborator responsibilities

Users should preserve project context, input provenance, version information, and the evidence used to interpret results.

Central scientific problem

Irrigation, rainfall, transpiration, soil evaporation, drainage, and root-zone depletion continue between satellite observations. BAITSSS is designed to maintain a continuous modeled accounting of those processes while using observations and forcing data to constrain the trajectory.

BAITSSS · scientific stewardship is part of responsible software use.
