## Source-confidence categories

1. **Published science:** externally documented peer-reviewed BAITSSS work.
2. **Maintained product documentation:** currently stated spatial-workflow behavior.
3. **Internal development-tested:** outputs and software behavior from recent development discussions, not reverified by GitHub source.
4. **Experimental/proposed:** optional optimization work and planned two-figure results/CSV interface.
5. **Not verified:** general availability, final installer release, final five-procedure UI, cross-machine benchmarks.

Do not collapse these categories into an unqualified “available now” claim.
