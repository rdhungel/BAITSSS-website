BAITSSS Desktop V1 is the first release version of a scientific desktop system for field-scale evapotranspiration, soil water, irrigation analysis, and field investigation.

From satellite and hourly weather inputs to completed scientific results.

The desktop workflow combines Landsat observations, terrain, soils, land cover, and NLDAS hourly weather with BAITSSS simulation and result analysis.
