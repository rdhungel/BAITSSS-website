Satellite-to-field desktop software.

BAITSSS is a scientific modeling system for field-scale evapotranspiration, soil water, and irrigation analysis.

Originally developed as a research model, BAITSSS is now being rebuilt as a desktop software system with reproducible workflows, transparent inputs and outputs, and tools for scientific evaluation.
