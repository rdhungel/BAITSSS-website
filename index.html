BAITSSS Desktop V1: field-scale ET, soil-water, and irrigation technology.

A working Windows product built around a mature scientific engine and years of accumulated model development, field evaluation, and software modernization. BAITSSS connects satellite, weather, vegetation, soil, and management inputs to hourly evapotranspiration, soil-water, irrigation, and spatial Results.

Technology asset

A scientific engine, a working desktop product, and an extensible foundation.

The value is not a single ET equation or one research result. It is the combination of scientific model development, accumulated evaluation, stateful hourly execution, data preparation, run control, Results, provenance, recovery, packaging, and a maintained product architecture.

Capability already in place

End-to-end field-scale water analysis

BAITSSS Desktop V1 already brings field definition, Landsat and weather preparation, vegetation and soil inputs, hourly model execution, evapotranspiration, soil-water state, modeled irrigation, maps, time series, and export into one project workflow.

What is difficult to reproduce

The accumulated scientific and software lineage

Rebuilding an equivalent foundation would require more than rewriting code. It would require recovering the scientific assumptions and parameter authority, reproducing long-run state behavior, rebuilding data and execution workflows, re-establishing numerical controls, and recreating the evaluation and publication record behind the model.

Extension path

A base for organization-specific systems

The present architecture can be extended for additional data sources, field sensors, APIs, cloud-connected services, automated data delivery, enterprise storage, and organization-specific workflows. Those are extension opportunities, not claims about features already shipped in Desktop V1.
