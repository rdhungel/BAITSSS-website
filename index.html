See your field in BAITSSS

Open BAITSSS. Find your field. We walk you through the rest.

The desktop already contains the tools needed to define the field, view its land cover, elevation and soil properties, set the simulation period, obtain Landsat and NLDAS data, run the model, and inspect the results.

01

Open BAITSSS

Create or open a project. Your field analysis stays inside one BAITSSS project.

02

Look at your field in the AOI Viewer

Locate the field and define or import the Area of Interest (AOI). BAITSSS shows the saved AOI directly on the map.

03

See the field information already available

BAITSSS displays the AOI over NLCD land cover, DEM/elevation, Soil Field Capacity, and Soil Available Water Capacity. These base layers are already part of the BAITSSS system.

04

Choose the simulation period

Set the exact start and end dates for the period you want BAITSSS to simulate.

05

Download Landsat and NLDAS from BAITSSS

Use File → Import → Landsat or File → Import → NLDAS. Each import window shows the registered archive and provides Download Missing for the data still needed by the project.

06

Run the simulation and inspect the field

Run the selected period, then inspect model outputs such as total evapotranspiration across the field. Return to the same project, change the period, update the data, and run again.

You do not start by building a GIS data stack

The BAITSSS desktop already works with the field's land cover, DEM/elevation, soil field capacity, and soil available water capacity. The field and these base layers can be inspected directly inside the project.

The changing inputs are handled inside the desktop workflow

Landsat and NLDAS are the time-dependent datasets shown in the BAITSSS import workflow. The software keeps registered data in its BaseData archive, shows what is already present, and provides Download Missing when additional files are needed for the selected work.

Your field, your period, your simulation.

BAITSSS is not just a place to view an ET map. It gives the user a repeatable field workflow: define the AOI, inspect the field data, choose the dates, obtain the changing inputs, run the simulation, inspect ET and water-balance results, then return and run another period when needed.
