System Requirements

BAITSSS Desktop runs locally on Windows.

This page separates what is already established from the hardware limits and recommendations that still require clean-machine and release testing.

Established now

These requirements describe the current desktop architecture without inventing minimum hardware numbers that have not yet been formally verified.

Platform

Windows desktop

BAITSSS is designed as a local Windows desktop application. A cloud computing environment is not required to execute the model.

Execution

Local CPU and memory

Simulation work is performed on the user's computer. Larger AOIs and longer simulation periods require more processor time, memory, and local storage.

Storage

Local project and BaseData storage

Projects, run information, and outputs are stored locally. Reusable environmental data are maintained in the BAITSSS BaseData archive, so available disk space matters for sustained use.

Internet

Needed for obtaining missing data

An internet connection is needed when BAITSSS must obtain missing supported Landsat or NLDAS data. The modeling workflow itself is local once the required project data are available.

Still under release verification

The following values will be published only after they are tested on clean Windows machines and representative BAITSSS projects.

Operating system

Supported Windows versions

The final supported Windows version list will be published with release packaging.

Processor

Minimum and recommended CPU

Formal minimum and recommended processor guidance is not yet published.

Memory

Minimum and recommended RAM

RAM requirements depend on project scale and will be published after clean-machine testing.

Disk

Installation and working-space guidance

Final installer size, BaseData storage guidance, and recommended free working space remain part of release verification.

Current guidance: do not treat unverified CPU, RAM, or disk numbers as official BAITSSS requirements. The formal minimum and recommended specification will be tied to a verified desktop release.
