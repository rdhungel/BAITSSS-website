Citation guidance

How to cite BAITSSS.

Use the scientific publication record for the model science. A version-specific citation for BAITSSS Desktop will be published with the first formal software release.

Current scientific citation

For research that uses or discusses the BAITSSS scientific model, cite the peer-reviewed BAITSSS publication or publications that are relevant to the scientific method, application, or comparison being reported.

View BAITSSS publications

BAITSSS Desktop

BAITSSS Desktop is currently a development build. There is not yet a formal version-specific software citation, DOI, or public release identifier.

When using a development build

Record the exact BAITSSS build or version identifier available in the software, the date of use, the simulation configuration, and the relevant scientific references.

Do not describe a development build as a formal public BAITSSS release.

What will be added at formal release

The first formal desktop release will include a stable software version, release date, version-specific citation guidance, and any persistent identifier or archival reference established for that release.

Citation of the software and citation of the underlying scientific methods are related but not interchangeable. A study should cite the software version used and the scientific publication or publications relevant to the methods being applied.
